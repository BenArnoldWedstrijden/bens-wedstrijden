# Ben's wedstrijden

De website van Ben's voetbalwedstrijden: https://ben.marcarnold.nl

- `index.html` is de site. Bezoekers kunnen alleen kijken.
- `data.json` bevat wedstrijden, toernooien, geplande wedstrijden en standen.
- `logos.json` bevat de clublogo's.
- Beheer: open https://ben.marcarnold.nl/#beheer en plak een fine-grained GitHub-sleutel (alleen deze repository, Contents: Read and write). Die sleutel wordt alleen op het eigen apparaat bewaard.
